# AI-Driven Performance and Tactical Analysis in Football
### Case Study: Nottingham Forest (2024–2025)

This repository contains the implementation of an AI-driven framework integrating:
• Computer Vision (YOLOv8 + ByteTrack)
• Statistical Learning (xG, xA, xT models)
• Game Theory (tactical simulations)

### 📌 Features
- Player and ball tracking from match videos
- Tactical structure and pressing analysis
- Expected Goals (xG) and attack quality metrics
- Build-up, transition, and defensive shape evaluation
